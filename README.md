# Programming Concepts Across Languages

> **Learning lab.** A reference I built to refresh core programming concepts across languages, so I can read and discuss code in whatever stack a team uses. My portfolio work is pinned on my [profile](https://github.com/aastha0208).

**12 core concepts × 5 languages — Java, Python, JavaScript, TypeScript and C# — as small runnable programs, side by side.**

Each topic is written once per language, so you can open the same idea in all five and see what's identical, what's similar and what's fundamentally different. Java is the anchor language, with a set of fundamentals to start from, and seven topics also have a written guide that compares the languages in one page.

## Quick language comparison

| Concept | Java | Python | JavaScript | TypeScript | C# |
|---|---|---|---|---|---|
| Typing | Static, strong | Dynamic, strong | Dynamic, weak | Static (compile-time), structural | Static, strong |
| `null` equivalent | `null` | `None` | `null` / `undefined` | `null` / `undefined` | `null` |
| String formatting | `String.format()` | `f"..."` | `` `${...}` `` | `` `${...}` `` | `$"..."` |
| List | `ArrayList<T>` | `list` | `Array` | `T[]` / `Array<T>` | `List<T>` |
| Map | `HashMap<K,V>` | `dict` | `Map` / `Object` | `Map<K,V>` / `Record<K,V>` | `Dictionary<K,V>` |
| Set | `HashSet<T>` | `set` | `Set` | `Set<T>` | `HashSet<T>` |
| Inheritance | `class Foo extends Bar` | `class Foo(Bar)` | `class Foo extends Bar` | `class Foo extends Bar` | `class Foo : Bar` |
| Interfaces | `interface IFoo` | `ABC` / duck typing | none (duck typing) | `interface IFoo` | `interface IFoo` |
| Error handling | `try/catch/finally` | `try/except/finally` | `try/catch/finally` | `try/catch/finally` | `try/catch/finally` |
| Checked exceptions | Yes (unique to Java) | No | No | No | No |
| Print | `System.out.println()` | `print()` | `console.log()` | `console.log()` | `Console.WriteLine()` |

## How to use it

1. **Start with the Java fundamentals**, `T01` to `T08` in order. Each is a standalone program. Predict the output before running it.
2. **Then go topic by topic.** Open the same `CL` file in all five languages side by side and note what changes.
3. **Read the guide** for topics 6–12 when you want the comparison in one page instead of five files.

Suggested pairings of fundamentals and topics: T01 + CL01 (types), T05 + CL02 (strings), T08 + CL03 (collections), T06 + CL04 (OOP), T07 + CL05 (exceptions).

## Running the examples

```bash
# Java — compile everything once, then run any class
javac java/basics/*.java java/crosslang/*.java
java -cp java basics.T01_DataTypes
java -cp java crosslang.CL01_TypeSystem

# Python
python3 python/CL01_TypeSystem.py

# JavaScript (Node.js)
node javascript/CL01_TypeSystem.js

# TypeScript (Node.js, no build step)
npx tsx typescript/CL01_TypeSystem.ts

# C# (.NET SDK + dotnet-script: dotnet tool install -g dotnet-script)
dotnet-script csharp/CL01_TypeSystem.cs
```

## If you know Java, start with C#

C# will feel the most familiar:

- Same static typing and primitive names (`int`, `long`, `double`, `char`)
- Same `class`, `interface` and `abstract class` concepts
- Same `try/catch/finally` and generics (`List<T>`, `Dictionary<K,V>`)
- Key differences: properties instead of getters and setters, `virtual`/`override` required for overriding, no checked exceptions, and `Console.WriteLine()` instead of `System.out.println()`
